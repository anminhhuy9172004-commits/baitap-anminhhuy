# World Market

World Market là dashboard theo dõi dữ liệu thị trường.

## Chức năng

- Giá xăng dầu Việt Nam
- Giá dầu thế giới
- Giá vàng
- Lịch sử giá
- Tin tức thị trường

## Công nghệ

- FastAPI
- SQLite
- Python
- HTML/CSS/JavaScript

## Chạy ứng dụng

python -m uvicorn app:app --host 0.0.0.0 --port 8000
